# הבוט של שודדים את אמזון

## מה הבוט עושה

**באינסטגרם (אוטומטי, דרך ה-API הרשמי של Meta):**

| מה קורה | מה הבוט עושה |
|---|---|
| מישהו כותב **כל תגובה** ישירות על הריל ("🔥", "וואו", "קישור", כל דבר) | שולח לו הודעה פרטית עם הקישור לעמוד של הסרטון (`/v/...`), ועונה בתגובה "שלחנו לך בפרטי 📩" |
| מישהו עונה על תגובה של מישהו אחר | לא עושה כלום |
| התגובה שלך (או של הבוט עצמו) | לא עושה כלום |
| אותו אדם מגיב כמה פעמים על אותו ריל | מקבל את הקישור רק פעם אחת |
| אי אפשר לשלוח לו הודעה (ההודעות שלו סגורות) | עונה בתגובה "הקישור בביו 👆" |
| הודעות פרטיות שמגיעות אליך | **לא נוגע בכלום**, ההודעות שלך |

כל הנוסחים מתחלפים באקראי (10 תשובות ציבוריות, 5 נוסחים להודעה), כדי שזה לא ייראה כמו ספאם.

הבוט קורא את רשימת הסרטונים ישירות מהאתר, אז **כל סרטון חדש שעולה לאתר מוכר לבוט אוטומטית**, בלי לעדכן אותו.

**בטיקטוק (חצי ידני):** לטיקטוק אין API שמאפשר לענות לתגובות, ובוט לא רשמי עלול לגרום לחסימת החשבון. לכן יש עמוד עם תשובות מוכנות לכל סרטון: לוחצים, התשובה מועתקת, ומדביקים. ראו סעיף "טיקטוק" למטה.

---

## איך הבוט יודע לאיזה סרטון התגובה שייכת

בכל קפשן באינסטגרם מוסיפים את **מילת הקוד** של הסרטון, בסוגריים בסוף. מילת הקוד היא הסוף של כתובת העמוד באתר:

```
שבת, 6 בבוקר 😴 תגיבו ונשלח לכם את הקישור בפרטי 📩 (vilon)
```

`primefindshq.github.io/v/vilon/` ← מילת הקוד היא `vilon`.

אם שכחתם מילת קוד, הבוט שולח את רשימת כל הסרטונים (`/v/`), כך שאף אחד לא נשאר בלי קישור.

## הקמה (פעם אחת, בערך 30-45 דקות)

### 1. חשבון אינסטגרם מקצועי
באינסטגרם: הגדרות ← סוג חשבון וכלים ← **מעבר לחשבון מקצועי** (Creator או Business).
ואז: הגדרות ← הודעות ותגובות לסיפור ← **כלים מחוברים** ← להפעיל **"אפשר גישה להודעות"**. בלי זה הבוט לא יכול לשלוח את הקישור בפרטי (הוא רק שולח, הוא לא קורא את ההודעות שלך).

### 2. אפליקציה ב-Meta
1. נכנסים ל-[developers.facebook.com](https://developers.facebook.com) ← My Apps ← **Create App**.
2. בוחרים את מקרה השימוש לניהול הודעות ותוכן באינסטגרם (**Instagram API**).
3. בעמוד **API setup with Instagram login**:
   - מוסיפים את חשבון האינסטגרם שלכם ומאשרים את ההרשאות `instagram_business_basic`, `instagram_business_manage_messages`, `instagram_business_manage_comments`.
   - לוחצים **Generate token** ומעתיקים את הטוקן. זה ה-`IG_ACCESS_TOKEN`.
   - ליד החשבון מופיע מספר. זה ה-`IG_USER_ID`.
   - באותו עמוד יש **Instagram app secret**. זה ה-`APP_SECRET`.

> ⚠️ **אישור של Meta:** כדי שהבוט יענה לכל אחד (ולא רק לאנשים שמוגדרים באפליקציה), ייתכן ש-Meta ידרשו להעביר את האפליקציה למצב **Live** ולעבור **App Review**: מסבירים מה הבוט עושה ומקליטים סרטון מסך קצר. זה תהליך של כמה ימים. עד אז אפשר לבדוק הכל עם חשבון שני שמוסיפים כ-Tester באפליקציה.

### 3. Cloudflare (חינם)
פותחים חשבון ב-[cloudflare.com](https://dash.cloudflare.com/sign-up) (את זה רק אתם יכולים לעשות). אחר כך בטרמינל, בתיקייה `bot`:

```bash
npx wrangler login
```

```bash
npx wrangler kv namespace create BOT_KV
```

הפקודה השנייה מדפיסה `id`. פותחים את `wrangler.toml`, מורידים את ה-`#` משלוש השורות של `[[kv_namespaces]]` ומדביקים את ה-id. באותו קובץ מחליפים את `PUT_YOUR_IG_USER_ID_HERE` במספר מסעיף 2.

### 4. הסודות
כל פקודה תבקש להדביק ערך:

```bash
npx wrangler secret put IG_ACCESS_TOKEN
```

```bash
npx wrangler secret put APP_SECRET
```

```bash
npx wrangler secret put VERIFY_TOKEN
```

ב-`VERIFY_TOKEN` ממציאים מילה אקראית כלשהי (למשל `shoded-2026-xyz`) וזוכרים אותה לשלב הבא.

### 5. העלאה

```bash
npm run deploy
```

מקבלים כתובת כמו `https://shodedim-bot.XXXX.workers.dev`. בדיקה מהירה בדפדפן:
`https://shodedim-bot.XXXX.workers.dev/try` מציג מה הבוט היה שולח למי שמגיב על הסרטון האחרון.

### 6. חיבור ל-Meta (Webhooks)
בעמוד האפליקציה ב-Meta, בחלק של **Configure webhooks**:
- **Callback URL:** `https://shodedim-bot.XXXX.workers.dev/webhook`
- **Verify token:** המילה שהמצאתם בשלב 4
- לוחצים Verify and save, ואז מסמנים **Subscribe** רק ל-`comments`.

### 7. בדיקה
מחשבון אחר (שמוגדר כ-Tester): כותבים תגובה כלשהי לריל, ובודקים שהגיעה הודעה עם הקישור ותגובה "שלחנו לך בפרטי". לוגים חיים:

```bash
npm run logs
```

## שימוש יומיומי
- **סרטון חדש:** מעלים אותו לאתר כרגיל, ובקפשן באינסטגרם מוסיפים `(מילת-קוד)`. זה הכל.
- **לשנות נוסחים:** הכל בקובץ `src/texts.js`. אחרי שינוי מריצים `npm test` ואז `npm run deploy`.
- **לחבר ריל ישן בלי מילת קוד:** ב-`wrangler.toml`, בשורה `MEDIA_MAP` שמים מספר מדיה ומילת קוד.
- **הטוקן:** טוקן של אינסטגרם פג אחרי 60 יום. הבוט מחדש אותו לבד כל יום שני (בתנאי שה-KV מחובר, שלב 3).
- **לא לחבר במקביל** כלי אוטומציה אחר (כמו ManyChat) לאותו חשבון, אחרת שניהם יענו.

## טיקטוק

```bash
py tiktok/make_replies.py
```

הפקודה יוצרת את `tiktok/replies.html`. פותחים אותו בדפדפן (אפשר גם לשלוח לטלפון). יש בו כרטיס לכל סרטון עם 4 נוסחים מתחלפים, ותשובות כלליות (מחיר, משלוח לישראל, תודה). לוחצים ← מועתק ← מדביקים בטיקטוק. מריצים שוב אחרי כל סרטון חדש.

כדאי לגוון בין הנוסחים: הרבה תגובות זהות ברצף עלולות להיחשב ספאם.

## קבצים
| קובץ | מה יש בו |
|---|---|
| `src/worker.js` | השרת: מקבל תגובות מאינסטגרם, בודק חתימה, שולח קישור |
| `src/logic.js` | ההחלטות: למי לענות (כן לתגובה על הסרטון, לא לתשובה על תגובה) ומה לשלוח |
| `src/texts.js` | כל הנוסחים בעברית |
| `test/test.mjs` | בדיקה מלאה בלי אינסטגרם (`npm test`) |
| `tiktok/make_replies.py` | מייצר את עמוד התשובות לטיקטוק |
