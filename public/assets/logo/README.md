# Logo assets

These are the **real, official PRIME.FINDS logo** — a gold "P/F" monogram
above the "PRIME.FINDS" wordmark and tagline — derived from the master brand
render at `scripts/logo-source/prime-finds-logo-master.png`. Everything here
is generated by `scripts/generate_logo_assets.py`; don't hand-edit these
files, edit the master and re-run the script instead.

| File | Used for |
|---|---|
| `mark.png` | Compact gold monogram, transparent — hero eyebrow badge, source for every favicon/app icon below |
| `wordmark.png` | Mark + "PRIME.FINDS" wordmark, transparent — desktop/mobile header, mobile menu, footer |
| `full-lockup.png` | Mark + wordmark + tagline, transparent — available for larger brand moments (About page, marketing) |
| `favicon.ico` | Legacy multi-res (16/32/48) browser favicon |
| `favicon-32.png`, `favicon-192.png`, `favicon-512.png` | Modern favicon + PWA icons, transparent |
| `apple-touch-icon.png` | 180×180, opaque brand-black background (iOS home screen) |
| `maskable-icon-512.png` | 512×512, opaque background with safe-area margin (Android maskable icon) |
| `og-image.jpg` | 1200×630 opaque social share image (Open Graph / Twitter card) |

To update the logo later: replace
`scripts/logo-source/prime-finds-logo-master.png` with the new master render
(same layout: mark on top, wordmark below, tagline at the bottom, on a solid
near-black background) and run:

```bash
python scripts/generate_logo_assets.py
python scripts/build.py
```

Every page references these files by the fixed names above, so nothing else
needs to change.
