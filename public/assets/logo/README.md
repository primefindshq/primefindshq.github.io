# Logo assets

These are **placeholder** logo files generated to match the PRIME.FINDS visual
identity (gold "P/F" monogram + wordmark) described in the brand brief. They
exist so the site is fully wired up and looks correct today.

**Replace them with the real, official logo files** the moment they're
available, keeping these exact filenames/paths so nothing else needs to
change:

| File | Used for |
|---|---|
| `mark.svg` | Compact monogram — mobile nav, favicon fallback, footer small mark |
| `wordmark.svg` | Full lockup (mark + "PRIME.FINDS" type) — desktop header, footer, social share card |
| `favicon.svg` | Browser tab icon |

All three are referenced by `<img>`/`<link>` tags across every page — swapping
the file contents (same filename, ideally same aspect ratio) is enough to
update the whole site everywhere the logo appears.
