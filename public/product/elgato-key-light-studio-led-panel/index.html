Elgato Key Light Studio LED Panel

About this product

The Elgato Key Light is a flat studio light built for desks, streaming setups and video calls. It uses 160 OSRAM LEDs behind an opal glass face for even, glare-free diffusion, outputs up to 2800 lumens and dims down to a low glow, per the listing. Color temperature adjusts from 2900K to 7000K. It connects over Wi-Fi so it can be switched on and fine-tuned from Elgato's desktop app. The box includes the light, a metal pole mount with desk clamp, a power supply and a quick start guide.

Why We Like It

It's the single biggest upgrade for how you look on camera, and because it clamps to the desk it doesn't eat floor space like a softbox. App control means no reaching behind the monitor.
