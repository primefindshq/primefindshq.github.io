LuvLink Infinity Voice Friendship Lamp, Set of Two

Check price 4.0(95)

About this product

The LuvLink Infinity Voice lamp is sold as a set of two: place your hand in one lamp's ring and both it and its paired lamp swirl the same color, wherever the second lamp is in the world. The LuvLink app lets you record and send short voice messages between the pair, and set up a color code for specific meanings like "goodnight" or "I miss you." The listing lists an improved Bluetooth setup and extended Wi-Fi range on this v2 version, no subscription required, and USB power. Lamps can be mixed and matched with other LuvLink designs, and more than two can be linked together, per the listing.

Why We Like It

It's a small, ongoing way to stay present with someone far away, a color instead of a text, that shows up as a physical object in the room rather than a notification. A genuinely thoughtful gift for a long-distance relationship, a college student, or family overseas.

Highlights

  • Set a custom color code for specific messages
  • No subscription required; USB powered
